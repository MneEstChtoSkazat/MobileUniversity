# Wallet5

«Android-приложение хранение цифровой валюты и поиска пунктов обмена валюты».>

## 1. План монетизации и публикации

### 1.1. Целевая аудитория

- Люди, которые ищут выгодный курс для обмена наличной валюты.
- Путешественники, которым нужен ближайший пункт обмена.
- Пользователи, следящие за курсами валют.

### 1.2. Модель монетизации

| Источник | Как работает | Комментарий |
|---|---|---|
| Бесплатная версия с рекламой | Небольшой баннер на экране курсов, без рекламы на карте | Основной источник на старте |
| Подписка «Pro» | Отключение рекламы, уведомления об изменении курса, избранные пункты | Небольшая цена за месяц или год |
| Партнёрство с пунктами обмена | Платное выделение пункта на карте, расширенная карточка с часами работы | Появляется после набора аудитории |

Базовый функционал (карта и курсы) остаётся бесплатным, чтобы набрать пользователей.

### 1.3. План публикации

1. **Подготовка релиза**
   - Выставить `versionCode` и `versionName`, `applicationId`.
   - Собрать подписанный релиз (APK для раздачи, AAB для магазина), включить минификацию R8.
   - Подготовить иконку, скриншоты (не менее 2–4), краткое и полное описание.
2. **Документы**
   - Политика конфиденциальности (приложение использует геолокацию и сеть).
   - Заполнение анкеты о данных и возрастного рейтинга.
3. **Площадки**
   - Google Play (платная разовая регистрация разработчика).
   - RuStore и другие российские магазины (проверьте актуальные условия регистрации).
   - Прямая раздача APK через GitHub Releases.
4. **Этапы выпуска**
   - Закрытое тестирование на 5–20 знакомых пользователях.
   - Открытое тестирование, исправление ошибок.
   - Публичный релиз.
5. **После релиза**
   - Сбор отзывов и сообщений о сбоях.
   - Обновление каталога пунктов и поддержка API.
   - Продвижение: описание в магазине (ключевые слова «курс валют», «обмен валюты»), посты в тематических сообществах.

## 2. Средства обеспечения безопасности

| Область | Мера |
|---|---|
| Сетевые запросы | Обращение к API только по HTTPS; запрет незашифрованного трафика (`usesCleartextTraffic="false"` или `network_security_config`) |
| Секреты | API-ключи не хранятся в коде и репозитории, а передаются через `local.properties` / `BuildConfig` |
| Разрешения | Запрашиваются только необходимые: интернет и геолокация; геолокация запрашивается во время работы (runtime-разрешение) с пояснением |
| Локальные данные | Данные хранятся в Room во внутреннем хранилище приложения, недоступном другим приложениям; персональные данные не собираются |
| Резервные копии | Отключено или настроено исключение чувствительных данных (`allowBackup`, `dataExtractionRules`) |
| Ввод данных | Проверка полей форм (пустые значения, формат чисел) до записи в БД; параметризованные запросы Room защищают от SQL-инъекций |
| Сборка | Релиз подписан собственным ключом; включены R8/ProGuard (сжатие и обфускация кода); `debuggable=false` |
| Компоненты | Неиспользуемые Activity и сервисы не экспортируются (`android:exported="false"`) |
| Зависимости | Используются актуальные версии библиотек из доверенных репозиториев (Maven Central, Google) |
| Приватность | Политика конфиденциальности описывает, какие данные используются и зачем |


## Стек

- Язык: Kotlin
- UI: Jetpack Compose
- Сборка: Gradle (Android Gradle Plugin)


## Требования для сборки

- [Android Studio](https://developer.android.com/studio) (актуальная стабильная версия)
- JDK 17 (встроен в Android Studio)
- Android SDK с платформой <compileSdk из app/build.gradle(.kts)>
- Эмулятор или устройство с Android <minSdk> и выше

## Сборка и запуск

### Через Android Studio

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/MneEstChtoSkazat/Wallet2.git
   ```
2. Откройте Android Studio → **File → Open** → выберите папку `Wallet2`.
3. Дождитесь завершения синхронизации Gradle.
4. Выберите эмулятор или подключённое устройство (с включённой отладкой по USB).
5. Нажмите **Run ▶** (`Shift+F10`).

### Через командную строку

Из корня проекта:

```bash
# Linux / macOS
./gradlew assembleDebug

# Windows
gradlew.bat assembleDebug
```

Готовый APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Установка на подключённое устройство:

```bash
./gradlew installDebug
```

### Релизная сборка

1. Создайте ключ подписи (**Build → Generate Signed Bundle / APK**) или через `keytool`.
2. Соберите подписанный APK или AAB:
   ```bash
   ./gradlew assembleRelease   # APK
   ./gradlew bundleRelease     # AAB для Google Play
   ```
3. Результат: `app/build/outputs/apk/release/` или `app/build/outputs/bundle/release/`.
